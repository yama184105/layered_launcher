Privacy Policy

Last updated: 2026-10-23

1. Overview

Layered Launcher ("the App") is a home launcher that runs on the user's Android device. The App does not collect personal information to transmit to external servers, nor share it with any third party. All settings and usage history are stored solely on the user's device (local storage). The only exceptions are the two optional features described in "4. Communication with external services": weather display and the online wallpaper gallery.

2. Information handled

The information the App handles on-device is listed below. None of it is transmitted off-device.

  • List of installed apps: read in order to lay out apps across floors
  • App launch history and counts: recorded for the "usage-driven floor change", "auto-move", and "app blocking" features
  • User settings: floor configuration, wallpaper, fonts, and other preferences
  • (Only when permitted) Notification metadata: source app and counts, used for notification batching
  • (Only when permitted) App usage statistics: read from the OS Usage API for the screen-time display, the recent-apps list, and usage-count / usage-time based mode switching
  • (Only when permitted) Approximate location: the last known latitude/longitude held by the OS is read for the weather display. It is not stored on the device
  • (Only when permitted) Calendar events: read to show upcoming events on the home screen. Never sent off-device

3. Storage

All of the above is stored only on the device using Hive (an on-device NoSQL store). No data is sent to any cloud, third-party server, or analytics service.

4. Communication with external services

The App does not share collected information with any third party. No advertising, analytics, or crash-reporting SDKs are bundled. Only when you use the following two optional features is the minimum information required for that feature sent to an external service.

  • Weather display: if location access is granted, the approximate latitude/longitude of your current position is sent to Open-Meteo (open-meteo.com) to fetch the forecast. No account or device identifier is sent.
  • Online wallpaper gallery: when you search for wallpapers, the search term you entered is sent to Unsplash (unsplash.com) to retrieve images.

If you do not use these features, the App never connects to the internet.

5. Permissions

The Android permissions requested by the App are:

  • QUERY_ALL_PACKAGES: enumerate installed apps (core launcher functionality)
  • PACKAGE_USAGE_STATS (optional): screen-time display, recent-apps list, and usage-count / usage-time based mode switching
  • BIND_NOTIFICATION_LISTENER_SERVICE (optional): notification batching, blocking, and history
  • BIND_DEVICE_ADMIN (optional): screen-lock gesture (e.g. swipe down to turn the screen off). The only policy used is "lock the screen"; the App never wipes data or changes passwords. You can revoke it at any time under Settings → Security → Device admin apps
  • SCHEDULE_EXACT_ALARM (optional): deliver batched notifications at the exact time you chose
  • POST_NOTIFICATIONS: notifications for Mindful Delay, auto-move, and batched delivery
  • ACCESS_COARSE_LOCATION (optional): weather display
  • READ_CALENDAR (optional): upcoming events on the home screen
  • INTERNET: used only by the weather display and the online wallpaper gallery
  • REQUEST_DELETE_PACKAGES: uninstall from the app-management screen (always via the OS confirmation dialog)
  • RECEIVE_BOOT_COMPLETED / VIBRATE / EXPAND_STATUS_BAR: restore scheduled notifications after reboot, haptic feedback, and expanding the notification shade

Optional permissions only activate the related features when explicitly granted by the user. The App's core functionality works without them.

6. Data deletion

Uninstalling the App causes Android to remove all stored data automatically. You can also delete data from "Settings → Data Management" inside the App.

7. Changes to this policy

If this privacy policy is updated, the "Last updated" date on this page will change, and significant changes will be announced through in-app notifications.

8. Contact

For questions about this policy, please open an issue at GitHub Issues.
