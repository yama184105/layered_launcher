プライバシーポリシー

最終更新日: 2026-10-23

1. 概要

Layered Launcher (以下「本アプリ」) は、ユーザーの Android スマートフォン上で動作するホームランチャーです。 本アプリは、ユーザーの個人情報を収集して外部サーバーに送信したり、第三者と共有したりすることはありません。 すべての設定および利用履歴はユーザーの端末内 (ローカルストレージ) のみに保存されます。 例外は「4. 外部サービスとの通信」に記載する天気表示とオンライン壁紙の2機能だけで、いずれも任意機能です。

2. 収集する情報

本アプリが端末内で扱う情報は以下のとおりです。これらはいずれも端末から外部に送信されません。

  • インストール済みアプリの一覧: フロアへの配置・表示順制御のために参照します
  • アプリの起動履歴・回数: 「使用回数による階層変更」「自動移動」「アプリブロック」機能のために記録します
  • 各種設定値: フロア構成・壁紙・フォント等のユーザー設定
  • (端末設定で許可した場合のみ) 通知内容のメタ情報: 通知バッチ処理機能のために、通知の送信元アプリ・件数を読み取ります
  • (端末設定で許可した場合のみ) アプリ使用時間統計: スクリーンタイム・最近使ったアプリの表示、使用回数・使用時間によるモード切替のために OS の使用時間 API を参照します
  • (端末設定で許可した場合のみ) おおよその位置情報: 天気表示のために、OS が保持する最後の位置 (緯度・経度) を読み取ります。端末内には保存しません
  • (端末設定で許可した場合のみ) カレンダーの予定: ホーム画面への予定表示のために読み取ります。端末外には送信しません

3. 保存場所

上記すべての情報は、Hive (オンデバイス NoSQL ストレージ) を用いて端末内のみに保存されます。 クラウド・第三者サーバー・解析サービスへの送信は一切行いません。

4. 外部サービスとの通信

本アプリは収集情報を第三者に提供しません。広告 SDK、解析 SDK、クラッシュレポート SDK 等の外部 SDK を一切組み込んでいません。 次の2つの任意機能を使う場合に限り、機能の実現に必要な最小限の情報が外部サービスに送信されます。

  • 天気表示: 位置情報の利用を許可した場合、現在地のおおよその緯度・経度を Open-Meteo (open-meteo.com) に送信して天気を取得します。アカウントや端末識別子は送信しません。
  • オンライン壁紙ギャラリー: 壁紙を検索した場合、入力した検索語を Unsplash (unsplash.com) に送信して画像を取得します。

これらの機能を使わなければ、本アプリはインターネットに一切接続しません。

5. 権限

本アプリが要求する Android の権限は以下のとおりです。

  • QUERY_ALL_PACKAGES: インストール済みアプリ一覧の取得 (ランチャーのコア機能)
  • PACKAGE_USAGE_STATS (任意): スクリーンタイム・最近使ったアプリの表示、使用回数・使用時間によるモード切替
  • BIND_NOTIFICATION_LISTENER_SERVICE (任意): 通知のまとめ配信・ブロック・履歴
  • BIND_DEVICE_ADMIN (任意): 画面ロックジェスチャ (下スワイプ等で画面を消す)。使う権限は「画面のロック」のみで、データの消去やパスワード変更は行いません。端末の「設定 → セキュリティ → デバイス管理アプリ」からいつでも解除できます
  • SCHEDULE_EXACT_ALARM (任意): まとめ通知を指定した時刻ちょうどに配信
  • POST_NOTIFICATIONS: マインドフルディレイ・自動移動・まとめ通知の表示
  • ACCESS_COARSE_LOCATION (任意): 天気表示
  • READ_CALENDAR (任意): ホーム画面への予定表示
  • INTERNET: 天気表示とオンライン壁紙ギャラリーの通信のみ
  • REQUEST_DELETE_PACKAGES: アプリ管理画面からのアンインストール (OS の確認ダイアログを経由)
  • RECEIVE_BOOT_COMPLETED / VIBRATE / EXPAND_STATUS_BAR: 再起動後の通知予約の復元、振動フィードバック、通知シェードの展開

任意権限はユーザーが明示的に許可した場合のみ機能します。許可しなくても本アプリのコア機能は動作します。

6. データの削除

本アプリをアンインストールすると、保存された全データは Android OS により自動的に削除されます。 アプリ内の「設定 → データ管理」からも個別に削除できます。

7. 本ポリシーの変更

本プライバシーポリシーが更新された場合、本ページの「最終更新日」を変更し、 重要な変更がある場合はアプリ内通知でお知らせします。
